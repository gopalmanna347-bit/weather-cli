# 🌦️ Weather CLI App

A simple command-line weather application built with Python using the OpenWeather API.

---

## 🚀 Features
- Get real-time weather data 🌍
- Temperature in Celsius 🌡️
- Humidity percentage 💧
- Weather description ☁️
- Simple CLI interface 💻

---

## 🛠️ Tech Stack
- Python 3
- Requests library
- OpenWeather API

---

## 📦 How to Run

```bash
pip install -r requirements.txt
python main.py
